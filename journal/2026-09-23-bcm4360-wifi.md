# BCM4360 Wi-Fi support

Date: 2026-09-23

The MacPro6,1 Wi-Fi device is a Broadcom BCM4360 (`14e4:43a0`). The kernel's
legacy `b43` driver binds to it but logs an unsupported 802.11ac PHY and does
not create a wireless interface. This is a driver mismatch, not a
NetworkManager or access-point configuration problem.

The supported Debian driver is the proprietary Broadcom STA `wl` module from
`broadcom-sta-dkms`, which is distributed in Debian's `non-free` component.
It requires headers for the running kernel.

`bootstrap.sh` enables `non-free` only when it is absent from a Debian source,
installs `linux-headers-$(uname -r)` and `broadcom-sta-dkms`, removes the
conflicting Broadcom modules where possible, and loads `wl`. It reports whether
a wireless interface is visible and requests a reboot if the interface does not
appear immediately.
